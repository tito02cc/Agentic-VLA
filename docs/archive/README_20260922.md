# CARVE-VLA

CARVE-VLA is a resource-aware Agentic runtime for reliable and efficient
execution around frozen Vision-Language-Action models. The current research
prototype combines:

- an event-triggered VLM Planner/Critic for task decomposition and semantic
  verification;
- a high-frequency deterministic Monitor for execution-risk signals;
- typed embodied tools, bounded recovery, safe stop and auditable traces;
- verified-procedure memory for warm starts and large/small model routing;
- a profile-driven Optimize Runtime with action-fidelity, latency, memory,
  deadline, closed-loop and fallback admission gates;
- PI0.5 and StarVLA PI-v3 as evaluated action policies behind replaceable VLA
  adapters.

The thesis direction is **multimodal embodied-agent systems and efficient
inference**. Agentic RAG-VLM is the structured reasoning foundation; CARVE-VLA
extends that work from operation reasoning to continuous VLA execution.

## System

```text
Task + deployable observations
        |
        v
verified memory -> VLM Planner/Critic -> typed task plan and tool intent
        |                  ^
        v                  | event / stage boundary
Agentic Harness -> Monitor -> VLA or bounded physical skill -> robot/simulator
        |                                                     |
        +---------- verification, recovery and audit <--------+

Optimize Runtime admits model profiles using fidelity + P95 + VRAM +
deadline + matched closed-loop behavior + fallback completeness.
```

The VLM does not emit joint actions. It selects schema-validated capabilities.
The VLA remains on the action path; the Monitor runs frequently at low cost;
Planner scheduling is profile-specific; the current RoboMME comparison plans
every action chunk. Event-triggered scheduling is not assumed to be admitted
for this configuration.

## Historical Evidence

The following tables describe earlier configurations, not the newly narrowed
route. The September 22 identity-memory extension was 1/5 versus 5/5 on five
fixed initial states; the two VideoRepick non-interference pairs were 1/2 versus
1/2. Neither is a full-benchmark result. The current JAX chain does not inherit
the earlier PyTorch speedups. See the technical report for batch provenance.

Formal task-success evidence comes from the audited LIBERO/LIBERO-PRO study and
an eight-task paired RoboMME GroundSG study. StarVLA PI-v3/RoboDojo provides a
second VLA small-sample closed-loop and controlled-recovery validation; it is
not presented as a full leaderboard result.

| Evidence | Result |
|---|---|
| Paired benchmark | 4 suites x 10 tasks x 10 states x 3 methods = 1,200 episodes |
| Task success | Frozen `180/400`, Fixed `181/400`, Full Agentic `183/400` |
| Statistical boundary | Agentic vs. Frozen exact McNemar `p=0.375` |
| RoboMME paired study | 8 tasks x 10 episodes x 3 conditions = 240 rollouts |
| RoboMME task success | Raw `23/80`, Harness `36/80`, Full Runtime `42/80` |
| RoboMME paired significance | Full vs. Raw `+23.8` points, McNemar `p=0.000157` |
| RoboMME runtime efficiency | Planner calls `-40.6%`, wall time `-28.1%` vs. every-chunk Harness |
| Execution efficiency | control steps `-7.2%`, VLA calls `-8.4%` |
| PI0.5 fast path | P95 `282.43 -> 54.67 ms`, `45/45` action fidelity |
| Planner low-memory tier | allocated VRAM `8.46 -> 3.08 GiB` with NF4 |
| Full embodied loop | `3/3`, including one recovery followed by success |
| Memory/model routing | two task families; repeated-task wall time up to `-73.1%` |
| RoboMME admission pilot | fixed text `1/5`, deployable BF16 VLM `4/5`, oracle upper bound `5/5` |
| GroundSG Planner NF4 gate | VRAM `9,120 -> 3,994 MiB`, but success `4/5 -> 2/5`; capacity fallback only |
| StarVLA PI-v3 fast path | Flow2 vs Flow4 paired mean latency `-23.37%`; action MAE `0.003251` |
| RoboDojo closed-loop gate | `build_tower` and `put_bottles_into_dustbin`: Flow4 `6/6`, Flow2 `6/6` |
| RoboDojo controlled stall | Optimize-only `0/3`, two-stage Agentic recovery `3/3`; McNemar `p=0.25` |
| VLM deployment boundary | Critic not admitted; StarVLA + 4B visual VLM single-4090 co-residency not established |
| Artifact audit | 1,200/1,200 videos decoded, 454,540 frames |

The LIBERO-PRO aggregate increase is small and not statistically significant;
the paired RoboMME Agentic result is statistically significant. CARVE's
supported value is the complete execution system, bounded correction, explicit
safety/authority boundaries, a realtime VLA path, and memory-driven compute
routing. The project does not claim SOTA, universal quantization, real-robot
transfer, or large-scale multi-VLA validation. RoboMME currently covers 8 of 16
official tasks and is a mechanism study rather than a full leaderboard claim.
The RoboDojo controlled-fault result is likewise mechanism evidence, not a
natural-task success-uplift claim.
