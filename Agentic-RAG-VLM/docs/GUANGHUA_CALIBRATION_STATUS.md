# 光华 MuJoCo 准入与标定状态

## 冻结门禁

| 门禁 | 判据 | seed 7 状态 |
|---|---|---|
| G0-A 感知预抓取 | 公开 RGB-D 红方块 XY 误差 ≤20 mm；末端误差 ≤35 mm；无易碎物非支撑接触；状态有限 | PASS |
| G0-B 接触抓取 | 闭合过程中无 MuJoCo reset/NaN；至少双侧持续接触；公开视觉验证抬升 ≥40 mm | NOT ADMITTED |
| G0-C 放置 | 公开视觉验证进入红区；私有评价器确认目标关系；无易碎物接触 | 未运行 |

G0-A 的正式输出位于 `output/g0_admission_seed7/`。Agent 侧只写入
`public_trace.jsonl`，真实物体位置和接触只进入 `private_evaluator.json`。
同目录的 `g0a_pregrasp_front.mp4` 是 5.05 s、20 fps 的诊断视频，只展示已通过的
安全预抓取，不代表抓取或放置成功。

G0-B 的系统性接触审计位于 `output/g0b_contact_admission_audit_v1/`。
`receipt.json` 的审计状态为 PASS，但物理准入判定为 `NOT_ADMITTED`：无接触控制稳定，
所有发生手—物接触的候选都会触发数值失稳，因而没有把任何闭合或提升片段计为成功。

## 已验证改动

- 机器人固定基座从 z=0.80 m 调整到 z=1.05 m，使向下抓取后仍有抬升空间；
- RGB-D 颜色定位使用最大连通域，排除机器人腕部同色小区域；
- IK 增加末端局部轴约束、关节连续性评分和多起点求解；
- 关节位置控制增加由模型偏置力计算的重力前馈；
- 灵巧手位置增益从 200 降至 30，并限制单关节执行器力为 ±8；
- 指尖/指节代理使用 3 mm 接触 margin，避免零距离瞬时硬碰撞。

上述改动均由 `scripts/prepare_assets.py` 或 `scripts/guanghua_control.py`
确定性生成，不依赖 evaluator-only 物体真值。

## 接触抓取未准入原因

在顶抓、侧捏、严格 IK、柔顺臂控制、小 timestep、PGS、软接触和不同接触余量等
多组标定中，自由空间/无接触运动保持稳定，但第一次手—物接触会使自由关节加速度或速度
越过数值保护阈值，随后模拟器复位。审计保留了每个候选的接触中心、速度、reset 和判据，
而非只保留最好看的片段。

当前不能把该 reset 解释为“抓取失败”，也不能把预抓取 PASS 解释为任务成功。
下一步应优先重建经过测量的指节碰撞代理、惯量和接触参数。G1–G4 的正式 Challenge v3
已经作为“高层机制 + 运动学/contact-assisted 技能代理”独立完成；只有 G0-B 连续通过后，
才能把同一套任务升级为接触动力学抓取/放置成功率实验。
