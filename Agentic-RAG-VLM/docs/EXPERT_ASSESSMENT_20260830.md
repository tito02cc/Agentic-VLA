# 当前光华仿真实验的专家审视（2026-08-30）

## 结论

当前成果已经足以作为中期答辩的核心仿真实验，也能作为机器人/具身智能面试中的完整系统
项目展示。正确定位是：**Agentic RAG-VLM 的任务级闭环、语义安全、记忆和失败恢复在光华
机器人上的可审计验证**，而不是“已经解决灵巧手接触抓取”或“已经完成 VLA/sim-to-real”。

按现有证据评估：框架完整度 A-，Agentic 机制证据 A-，仿真运动执行 B，接触动力学抓取
C-/尚未准入，sim-to-real 尚未开始。对中期答辩是可用且有辨识度的；若作为新的机器人实验
论文完整实验章节，仍需补真实接触抓取、更大规模随机布局和实机结果。

## 最有说服力的部分

1. 比较隔离较公平：T0、强 T1 和 Agentic 共享 RGB-D 与 IK 执行器，T1 还允许几何抓法启发式、
   全布局调优的固定腕角和视觉变化重规划。
2. 没有隐藏负结果：T1 在已知几何体 E1 与 Agentic 打平；Agentic 在 E2 仍有 1/8 因 6.8 mm
   净空不足而安全拒绝。
3. 黄色物体具有可检验意义：它是 Protected Glass，不是装饰或第三目标；自然语言约束被转成
   场景图关系、腕角/路径选择和最小净空指标。
4. 失败恢复不是一句话：F0/F4 是负控制，F1/F2 检查 L1/L2 状态选择，L3 由真实 MuJoCo
   pending-target 外部位移支撑，并保留已完成红色子任务记忆。
5. 执行观感与审计已改善：抓取中心来自指尖几何，加入手型预成形、自然姿态 IK、完整末端朝向、
   桌面净空与关节限位门禁；四场景视频全部通过自动审计。
6. Challenge v3 已完成 100 个冻结方法 rollout、195 次真实 Qwen3.5-4B 多模态调用；Full Agent
   在 G1–G4 均为 10/10，public/private 审计检查 260 个公开事件，工具合约审计检查 60 次调用。
   强消融保留自然的部分成功（G3 no-replan 5/10，G4 skill-only 1/10），不是刻意制造全败。

## 必须主动披露的边界

- 物体运输仍是明确记录的 kinematic grasp-skill proxy；G0-B 接触闭合到提升尚未通过，因此不能
  报告真实 grasp/lift success rate。
- L1/L2 是 controlled verifier fault injection，用于隔离恢复状态机；不能称为自然发生的物理
  失败。L3 才有实际仿真场景位移视频。
- 批量机制评估使用冻结、可审计的语义/几何接口；保存的 Qwen3.5-4B 凭据支持抓法选择，但当前
  不是端到端在线 VLM 控制全部低层动作。
- E2/E3/E4 的传统基准布局数为 8/12/8；Challenge v3 另有十个冻结主种子、Wilson CI、
  McNemar 配对检验和事件切片。样本量已经足够支撑中期机制结论，但还不能代表大规模泛化。

## 答辩最可能被问到的问题

**“这是不是假抓取？”** 运输阶段是公开标注的运动学技能代理，不冒充接触成功；当前主张是
验证任务级 Agentic 闭环和安全执行。接触动力学 G0-B 是下一阶段独立准入门。

**“为什么传统检测加 IK 不行？”** 它在已知几何抓法上可以很好，E1 的强 T1 已经打平。差异
出现在未硬编码的语义角色、关系安全、变化归因和有预算的恢复：E4 为 T0 0%、T1 50%、A2
87.5%。

**“失败是不是人为制造的？”** L1/L2 明确是受控注入，目的是验证恢复策略选择；不将其包装
成物理失败。当前 L3 视频是场景中蓝色目标真实移动 80.0 mm；旧路点因对齐误差被门禁拒绝，
Agentic 侧从重新观测生成有界重规划。两侧逐帧可见网格审计通过，不靠穿模制造失败。

**“VLM 到底做了什么？”** Qwen 提出多模态高层候选；RAG 卡片、保护关系和变化/memory 分别
经三个公开输入的确定性工具契约转成手型、运动约束和恢复决策，原始提议与工具执行结果均留档。
IK/灵巧手技能负责低层确定性执行。相同执行器的成对基线避免把 IK 改进误算成 Agentic 增益。

## 下一阶段的优先级

1. 最高优先级：完成 MuJoCo 接触闭合、稳定提升与放置，预注册 20–50 个种子并报告成功率。
2. 从现有十个冻结主种子扩展到 30–50 个随机布局，并加入遮挡和未见描述，继续报告 CI 与安全拒绝率。
3. 现有实验已报告调用、延迟、token、无 RAG/graph/memory/replan 和固定技能；下一步补模型规模、
   量化和感知噪声敏感性。
4. 在上述门禁稳定后再做实机标定、相机外参、控制频率和 sim-to-real，而不是直接跳到 VLA
   重训练。
