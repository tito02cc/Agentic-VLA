## 1. 项目定位

**项目名称：** Agentic RAG-VLM：面向人形机器人操作的可供性感知检索与自反思规划框架  
**论文成果：** *Agentic RAG-VLM: Affordance-Aware Retrieval-Augmented Generation with Self-Reflective Planning for Robotic Grasping*，IROS 2026 第一作者录用（用户确认）  
**项目周期：** 2025.07–2026.03  
**技术方向：** 多模态 Agent、RAG、机器人操作、场景图、任务记忆、失败恢复

一句话概括：这个项目不是让 VLM 直接输出机械臂关节角，而是让 VLM 理解任务和场景，
再通过可供性检索、空间约束工具、任务记忆和自反思恢复，把高层语义逐步转化为可执行、
可检查的机器人操作决策。

## 2. 研究背景与问题

传统视觉抓取通常遵循“检测目标—估计位姿—求解 IK—执行”的流程。在物体单一、布局固定时，
这类方法可以有效工作；但进入杂乱、交互式和长程任务后，会遇到三个问题：

1. **经验误检索：** 视觉相似不等于操作方式相同。外形相似的杯子与玻璃容器，可能分别需要
   抓把手和低力度侧抓；仅依赖 CLIP 或类别相似度容易返回错误经验。
2. **缺少空间约束：** 目标物不能脱离周围环境单独规划。邻近易碎物、容器内液体、支撑关系和
   遮挡关系都会改变接近方向、抓取力度和任务顺序。
3. **失败后难以恢复：** 开环规划通常只给出一次动作；当出现位置偏差、抓取宽度不匹配、滑落
   或场景发生变化时，系统缺少结构化诊断和针对性修正。

Agentic RAG-VLM 的目标，是在不针对每个新物体重新训练策略的情况下，利用外部操作经验、
空间关系和执行反馈，形成“理解—规划—执行—验证—恢复”的任务级闭环。

## 3. 整体工作流程

```text
RGB-D + 自然语言任务
          │
          ▼
   VLM 场景与目标理解
          │
          ├── HAA-RAG：检索适合当前物体的操作经验
          ├── 场景图：识别邻接、包含、支撑和遮挡关系
          └── 任务记忆：区分已完成目标与待执行目标
          │
          ▼
   Agent 工具将语义转成可执行约束
   （抓取策略 / 安全偏置 / 高度 / 力度 / 是否重规划）
          │
          ▼
   带姿态和关节限制的逆运动学与机器人技能执行
          │
          ▼
   结果验证与场景变化监测
          │
      成功 ──► 写入记忆并继续下一子任务
      失败 ──► L1 参数调整 / L2 方法切换 / L3 完整重规划
```

当前工程将这个过程实现为显式状态机：
`OBSERVE → PLAN → EXECUTE → VERIFY → MONITOR → REPLAN`，并提供 `COMPLETE` 与
`SAFE_STOP` 终止状态。已完成子任务不会因为后续目标变化而被重复执行；只有发生变化且仍处于
 pending 状态的目标才会触发重规划。

## 4. 核心方法

### 4.1 HAA-RAG：按“怎么操作”检索，而不是只按“长得像”检索

论文构建了包含116条操作经验的知识库。每条经验除了物体类别和视觉特征，还记录四维可供性
描述符：

- affordance type：适合整体抓取、捏取、包覆、边缘抓取或工具把手等；
- material：陶瓷、玻璃、金属、塑料等；
- fragility：物体脆弱程度；
- graspable region：本体、边缘、把手等可操作区域。

检索采用三级粗到细流程：

1. 类别匹配，排除无关经验；
2. 按可供性类型、材质、脆弱性和可抓区域筛选功能兼容经验；
3. 在功能兼容候选中进行视觉相似度重排，返回 Top-3 操作策略。

最终经验不只是一个文本提示，而是包含抓取类型、开口宽度、力度和接近方向的结构化策略。
工程版本保留了同样的 `0.2×类别 + 0.4×可供性 + 0.4×视觉` 评分结构，使用8条可审计卡片
覆盖 power、pinch、side 等策略，并将检索结果通过工具路由到实际执行字段。

### 4.2 场景图约束推理：把空间语义转成动作参数

系统以物体为节点、空间关系为边构建场景图。论文定义16种空间关系，并重点处理四类操作约束：

- **内容保持：** 盛有内容物的容器采用竖直接近与低速运动；
- **碰撞规避：** 目标靠近易碎物时降低力度、增加接近高度，并沿远离易碎物方向偏置；
- **支撑依赖：** 目标支撑其他物体时，先处理上方物体；
- **遮挡处理：** 直接视线或路径受阻时切换为侧向接近。

这些关系最终被编译为抓取调整量，而不是停留在“附近有障碍物”的文字描述。当前演示中的黄色
物体就是受保护对象：它不属于待抓目标，用于验证系统能否把“禁止碰撞/易碎”转化为安全偏置、
高度和力度限制。

### 4.3 Agentic 自反思规划：失败后判断“为什么”，再决定“怎么改”

系统采用 ReAct 风格的 `Thought → Action → Observation → Reflection` 循环。论文使用七因子
质量模型评价位置准确性、宽度兼容性、力度合理性、抓取类型、接近净空、物体难度和抓取稳定性，
并将失败划分为14类：

- 预接触：位置误差、不可达位姿、接近角错误；
- 接触阶段：宽度不匹配、碰撞、姿态错误；
- 抓取后：滑落、掉落、力度损伤、形变；
- 任务层：抓错目标、违反约束、超时和未知错误。

恢复策略按成本逐级升级：

- **L1 参数调整：** 修改力度、开口宽度、接近高度或重新定位；
- **L2 方法切换：** 在 power、pinch、side 等抓取方式之间切换；
- **L3 完整重规划：** 重新观察环境、保留已完成任务记忆，只为失效的 pending target 生成新计划。

### 4.4 Episodic Memory：避免重复探索和错误回滚

成功策略写入 session-level episodic memory。论文用它实现同类物体之间的经验迁移；当前多目标
运行时还用 memory 维护已完成子任务。例如红色目标完成后，即使蓝色目标被外部移动，系统也只
重新规划蓝色目标，不会重复执行已经完成的红色任务。

## 5. 当前工程实现

论文方法之外，当前仓库完成了以下工程化工作：

1. **可替换 Agent 运行时：** 将 perception、planner、robot executor、public verifier 和
   private evaluator 抽象为独立接口，使同一高层框架后续可以接入其他机器人或 VLA executor。
2. **真实多模态模型调用：** 通过 OpenAI-compatible 接口调用本地 Qwen3.5-4B，保存图像、
   prompt、原始输出、结构化解析、修复记录、token 与延迟。
3. **公开 RGB-D 感知：** 从相机 RGB 与深度恢复可见物体三维位置和表面范围，通过颜色、连通域
   和公开高度包络排除机器人同色高光，不向 Agent 提供物体真值位姿。
4. **模型显式选择的 Agent 工具：** Qwen先在独立路由回合选择所需工具，再由三类公开观测工具
   分别将检索结果转换为抓取策略、将受保护关系转换为偏置/高度/力度约束、将场景变化与任务
   记忆转换为重规划决策；实验场景编号不参与工具分派。
5. **机器人执行层：** 完成人形机器人模型、桌面与任务物体环境接入，实现多起点完整朝向 IK、
   自然姿态正则、重力前馈、抓取预成形、关节限位和桌面净空门禁。
6. **可审计证据链：** 将 Agent 可见的 `public_trace` 与只用于评分的 `private_evaluator` 分离，
   防止评价答案泄漏进模型上下文；配置、知识卡哈希、视频哈希和验证收据均留档。

模型先选择工具并提出“语义候选”，工具负责校验公开输入并执行确定性的数值规则，低层控制器
执行受约束动作。原始路由、候选、工具执行和拒绝原因均写入公开轨迹。这样既
保留了 VLM 对开放任务的理解能力，也避免让模型直接生成不可检查的关节控制量。

## 6. 实验与结果

### 6.1 论文实验

论文在12项任务上进行评估，包括6项单物体抓取、4项带空间约束的交互任务和2项长程多物体
任务，每个配置共360次试验。论文报告：

- Full System 总体成功率 **78.3%**，VLM-only 为 **25.0%**；
- 去除 HAA-RAG 后总体下降53.3个百分点，是影响最大的模块；
- 去除恢复机制后从78.3%降至46.7%；
- 去除场景图后，交互任务从64.2%降至25.0%；
- 去除 episodic memory 后，长程任务从66.7%降至55.0%；
- HAA-RAG 的检索 P@1 为91.7%，CLIP-only 为66.7%；
- 面对完全未见类别时仍保持54.4%的成功率。

这些结果说明：HAA-RAG主要解决经验是否适用，场景图主要解决复杂环境中的空间安全，自反思
恢复主要解决首次执行失败，memory主要服务多步骤任务。

### 6.2 当前工程验证

当前人形机器人版本没有直接复用论文缺失的原始116条经验和试验日志，而是在冻结协议下重新
建立了可审计的机制评测：

- 10个冻结种子、100个方法 rollout；
- 246次真实 Qwen3.5-4B 多模态调用，最终 endpoint error 为0；
- 60次 Agent 工具调用与260个公开事件通过 public/private 隔离审计；
- 完整方案在可供性路由、空间安全、变化恢复和联合任务四类测试中均为10/10，模型工具选择
  准确率均为100%；
- VLM-only、no-graph、no-memory、no-replan、local 与固定技能基线用于隔离各模块作用；
- 4组连续任务演示覆盖普通执行、受保护关系、目标变化恢复和综合场景；最终视频额外加入
  固定视觉+IK与Agentic方案的受保护净空、目标变化恢复配对对照；
- 自动测试共40项，正式评测、工具合约、视频运动和证据完整性均有验证收据。

传统视觉+IK在简单、已知几何任务上可以与Agentic方案打平。该框架真正的优势不是“让IK更准”，
而是让系统处理没有被固定规则预先编码的操作语义、物体关系、任务状态和环境变化。

## 7. 项目的核心价值

从研究角度看，项目将RAG从文本知识问答扩展到机器人操作经验检索，并把VLM语义、空间关系和
失败反馈统一到可执行的操作闭环中。

从工程角度看，项目不是一个只输出文字的多模态Agent：模型输出会经过结构化schema、工具合约、
任务状态机、运动约束和验证器，最终形成可以回放和审计的机器人执行轨迹。

从应用角度看，框架与具体低层策略解耦。后续可以保留RAG、scene graph、memory和recovery，
只替换RobotExecutor，将当前机械臂控制技能接到VLA策略或真实机器人SDK。

## 9. 两分钟面试介绍

“这个项目关注的是复杂环境中的机器人抓取。传统VLM通常根据视觉相似度选择经验，但外形相似的
物体不一定适合相同抓法；同时，目标周围的易碎物、遮挡和支撑关系也会影响执行，一旦第一次抓取
失败，开环系统通常缺少恢复能力。

因此我们提出Agentic RAG-VLM。第一部分是HAA-RAG，它在类别匹配后，进一步根据可供性类型、
材质、脆弱性和可抓区域筛选经验，再结合视觉特征重排，所以检索到的是功能上适用的操作策略。
第二部分是场景图推理，把邻接、包含、支撑和遮挡关系转换成接近方向、抓取力度和执行顺序等具体
约束。第三部分是自反思规划，通过14类失败诊断和三级恢复策略，逐步执行参数调整、方法切换和完整
重规划，并用任务记忆保留已经完成的子目标。

在工程上，我进一步把框架接入人形机器人操作环境，打通RGB-D感知、Qwen3.5-VL高层决策、
Agent工具、机械臂逆运动学控制和任务验证，并设计100组对比实验以及4组连续任务演示。结果表明，传统方法在
简单固定任务中也能工作，但当任务同时涉及操作经验、安全关系和环境变化时，完整Agentic框架的
优势更加明显。”

## 10. PPT与视频演示顺序

建议主讲视频控制在25–35秒，按以下顺序展示：

1. 给出任务与场景，明确黄色物体是受保护对象而不是第三个目标；
2. 展示HAA-RAG为不同几何物体选择不同抓取策略；
3. 展示场景图将邻接关系转换为远离易碎物的执行约束；
4. 完成第一个子任务并写入memory；
5. 外部移动尚未完成的目标，Agent检测计划过期并触发一次L3重规划；
6. 展示最终任务完成，再用一页对比实验说明去除RAG、graph或memory后的变化。

67.0秒完整视频用于备用或自由问答，不建议在自我介绍阶段完整播放。

## 11. 回答边界问题

如果被问“是不是端到端VLA”，应回答：当前采用VLM高层决策与确定性低层技能分层架构，重点验证
Agentic机制；后续可以将RobotExecutor替换成VLA策略。

如果被问“是不是实机”，应按实际情况说明当前完成的是人形机器人操作环境与连续任务验证，尚未
开展sim-to-real。

如果被问“是否是真实接触抓取”，应说明当前连续演示采用校准的操作技能代理；接触动力学闭合和
提升仍是单独准入项，因此不将机制测试的10/10表述为物理抓取成功率。

这些边界无需放在简历正文中，但面试时必须能够准确说明。
